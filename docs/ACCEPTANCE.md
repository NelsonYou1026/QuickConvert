# 人工驗收清單

記錄 OS 版本、CPU、引擎版本、簽章團隊與每項結果。以下項目無法由單元測試或 universal 編譯取代。

- [ ] macOS 13 + Intel：主程式、原生轉檔、FFmpeg、LibreOffice、Finder 選單可用。
- [ ] macOS 13 + Apple Silicon 與目前 macOS：完成相同流程。
- [ ] 有效 Developer ID 簽章、公證後，從 DMG 安裝到 Applications，可通過 Gatekeeper 並啟用 Finder 擴充。
- [ ] 選 WAV 只見音訊目標；選圖片只見圖片／PDF；選 Office 只見 PDF；混合不同類別與不支援檔案不出現選單。
- [ ] 選不同音訊格式時隱藏會造成相同格式輸入的目標；同類型批次每個檔案皆轉換。
- [ ] 在主程式分別關閉圖片 PDF 與文件 PDF，確認兩種選單設定獨立且跨程序即時反映。
- [ ] Finder 桌面、Documents、外接硬碟及含空格／中文／符號路徑皆可使用；雲端檔案須先下載至本機。
- [ ] 實際 DOCX（表格）、XLSX（多工作表）、PPTX（多頁）、HTML（本地圖片）轉 PDF，驗證頁數、可讀文字、版面和字型。含外部連結的文件不能建立網路連線；遠端圖片不載入。
- [ ] MP3／WAV／FLAC／M4A／AAC／OGG 輸入及四個輸出，驗證可播放、聲道及時長；無音軌／損壞輸入顯示個別錯誤。
- [ ] PNG／JPEG／WebP／HEIC／TIFF 輸入及四個輸出，確認 EXIF 旋轉與 JPEG 透明填白；多頁／動畫只取第一頁／影格。
- [ ] 沒有 FFmpeg、LibreOffice、libwebp 時，顯示可用的指引，原生轉換仍可用。
- [ ] 完整版本在沒有 Homebrew／外部轉檔工具的新帳號上，顯示引擎已內附，首次啟動無下載且能轉換所有 MVP 類別。
- [ ] 搬移 App 至含空白／中文路徑，清除非系統 PATH，以 --bundled-only 轉檔；確認簽章、函式庫與第三方來源／授權檔完整。
- [ ] 通知允許時有開始與完成／錯誤提示；通知拒絕時仍可在主程式查看結果。
- [ ] 大檔案批次期間 Finder 可操作；取消不發布不完整輸出，已完成檔案保留。再次右鍵提交的工作依序執行。
- [ ] 來源資料夾無寫入權限、滿碟、來源被移除、目的地已存在與連續提交時，回報錯誤或使用流水號，不覆寫原始資料。
- [ ] 記錄至少 30 次 Finder 選單回呼及暖／冷啟動時間，分開報告 P50/P95；選單呼出與啟動低於 0.5 秒的需求須以實機數據驗收，不能由格式計算測試推定。
- [ ] 發布版內附引擎版本與 SHA-256 正確、第三方授權與對應來源完整，無遙測、無轉檔 IP 網路流量；Homebrew Cask 可安裝、升級、移除。
